🎵 Terminal Music Player

A lightweight terminal-based music player that lets you play and manage your music directly from the command line.

✨ Features
🎵 Play music directly from the terminal
⏸️ Pause and resume songs
⏭️ Skip to the next song
⏮️ Go back to the previous song
📋 View available songs
🔀 Shuffle songs
🔁 Repeat songs or playlists
🎶 Create and manage playlists
🔊 Control playback from the terminal
⚡ Simple and fast CLI interface
🛠️ Tech Stack
Node.js
JavaScript
Command Line Interface (CLI)
